## 👥 Rôles & Responsabilités

### 🧠 Superviseur (IA Chat)
> *Architecte stratégique — pense, décide, challenge*

- Définit l'**architecture** et la **direction** du projet
- Découpe les tâches en **étapes ordonnées**
- **Valide / rejette** les propositions de l'exécutant
- **Debug profond** en cas de blocage
- **Code review critique** (sécurité, perf, cohérence)
- Propose des **solutions innovantes**
- Produit le **prompt de passation** en fin de session

### ⚙️ Exécutant (Kilo Code — IA interne VS Code)
> *Mains techniques — exécute, rapporte, propose*

- **Accès global** au code, infra, états des lieux
- **Rapporte l'état** de chaque fonctionnalité
- **Exécute** : implémentation, correction, recherche
- **Donne son avis** sur la cohérence
- **Fournit** diffs, logs, résultats

### 🧑 Coordinateur (Humain)
> *Chef d'orchestre — transmet, arbitre, valide*

- **Transmet** les ordres entre superviseur et exécutant
- **Arbitre** en cas de désaccord
- **Intervient manuellement** si l'exécutant bug
- **Valide** les étapes franchies
- **Garde** la vision produit & les contraintes business

## 🔄 Cycle de Session

```
┌─────────────────────────────────────────────────────────────┐
│  PHASE 0  · Ouverture        → Coordinateur transmet contexte │
│  PHASE 1  · Cadrage          → Superviseur découpe les étapes │
│  PHASE 2  · Transmission     → Ordre formaté pour Exécutant   │
│  PHASE 3  · Exécution        → Exécutant agit et rapporte     │
│  PHASE 4  · Revue            → Superviseur valide / ajuste    │
│  PHASE 5  · Clôture          → Passation pour session N+1     │
└─────────────────────────────────────────────────────────────┘
```

## 🚦 Règles Fondamentales

1. **Aucune session ne démarre sans le prompt de passation de la précédente.**
2. **Aucune étape n'est validée sans revue du superviseur.**
3. **Aucune décision d'architecture n'est prise par l'exécutant seul.**
4. **Tout changement en base ou en infra est tracé dans `SESSION.md`.**
5. **En cas de conflit : le coordinateur humain tranche.**
6. **Tout blocage > 2 tentatives de l'exécutant → escalade au superviseur.**
7. **Chaque fin de session produit un prompt de passation complet.**
