# SESSION-2026-10-30-E86-A-FIX10

## §1 — Contexte

Correction de l'erreur de build Next.js liée au chargement des polices par `next/font/google`.
Migration vers des polices hébergées localement (`next/font/local`) afin de rendre le build stable et indépendant de Google / Turbopack.

## §2 — Diagnostic

- `src/app/layout.tsx` déclarait trois polices via `next/font/google` : `Inter`, `Poppins`, `Fira_Code`.
- Next.js tente de télécharger les polices Google **au moment du build**. Parfois, Google répond avec une URL sans extension de fichier (ex: pas de `.woff2`). Turbopack, qui analyse cette réponse, échoue à parser l'URL et fait planter le build. Échec intermittent, sans modification de code.
- Cause racine : dépendance au réseau Google au moment du build + incompatibilité de parsing Turbopack.

### 3.2 Nouveau fichier `src/app/fonts/index.ts`

Déclare les trois polices avec `next/font/local` (`localFont`), conservant les mêmes variables CSS (`--font-sans`, `--font-heading`, `--font-mono`) et `display: 'swap'` qu'avant.

```ts
import localFont from 'next/font/local';

export const inter = localFont({
  src: [
    { path: './Inter-300.woff2', weight: '300', style: 'normal' },
    { path: './Inter-400.woff2', weight: '400', style: 'normal' },
    { path: './Inter-500.woff2', weight: '500', style: 'normal' },
    { path: './Inter-600.woff2', weight: '600', style: 'normal' },
    { path: './Inter-700.woff2', weight: '700', style: 'normal' },
  ],
  variable: '--font-sans',
  display: 'swap',
});

export const poppins = localFont({
  src: [
    { path: './Poppins-400.woff2', weight: '400', style: 'normal' },
    { path: './Poppins-500.woff2', weight: '500', style: 'normal' },
    { path: './Poppins-600.woff2', weight: '600', style: 'normal' },
    { path: './Poppins-700.woff2', weight: '700', style: 'normal' },
  ],
  variable: '--font-heading',
  display: 'swap',
});

export const firaCode = localFont({
  src: [
    { path: './FiraCode-400.woff2', weight: '400', style: 'normal' },
    { path: './FiraCode-400.woff2', weight: '500', style: 'normal' },
    { path: './FiraCode-400.woff2', weight: '600', style: 'normal' },
  ],
  variable: '--font-mono',
  display: 'swap',
});
```

### 3.3 Remplacement des imports dans `src/app/layout.tsx`

Avant :
```ts
import { Inter, Poppins, Fira_Code } from 'next/font/google';
const inter = Inter({ subsets: ['latin'], weight: ['300','400','500','600','700'], variable: '--font-sans', display: 'swap' });
const poppins = Poppins({ subsets: ['latin'], weight: ['400','500','600','700'], variable: '--font-heading', display: 'swap' });
const firaCode = Fira_Code({ subsets: ['latin'], weight: ['400','500','600'], variable: '--font-mono', display: 'swap' });
```

```ts
import { inter, poppins, firaCode } from '@/app/fonts/index';
```
Le `className` du `<body>` conserve `${inter.variable} ${poppins.variable} ${firaCode.variable}`.
