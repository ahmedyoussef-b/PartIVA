## Choix techniques
- **pgvector/Prisma** : requête sur `Part` avec inclusion images/catégorie; scoring heuristique basé sur `IngestResult`
- **Recherche web** : appel vers `/api/search?source=all` avec timeout 3s, gestion via `Promise.allSettled` style
- **Agrégation** : fusion, déduplication par `fileUrl`/`id`, tri par score décroissant
- **Modes** : `quick` (local uniquement), `deep` (local d'abord, web si < 3 exploitables ou tous < threshold)
- **Seuil** : 0.7 par défaut, `searchStatus` found/partial/not_found
