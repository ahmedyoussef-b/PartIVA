## §1 — Contexte

Objectif : permettre la conversion d'un `SearchCandidate` (résultat de recherche du moteur IA, affiché dans `CandidateCard`) en une `Part` (pièce) dans Prisma, via un bouton "Convertir en pièce".

Contraintes identifiées dans le rapport d'état des lieux E74 :
- `createPart` (`src/lib/actions/parts.ts`) est réservé au rôle **ADMIN** et exige `partNumber` + `name` obligatoires.
- Aucun `partNumber` côté `SearchCandidate` → génération automatique requise.
- Aucun bouton de conversion ni état `selectedCandidate` n'existaient.
- `Part.printableModelUrl` et la relation `Attachment` (types `CAD_STL/CAD_STEP/CAD_OBJ`) disponibles pour stocker le fichier 3D.

Option retenue : **Option A** — bouton "Convertir en pièce" dans `CandidateCard`, appel d'une nouvelle action serveur dédiée.

## §2 — Modifications

### 2.1 Nouveau fichier : `src/lib/actions/convert-candidate.ts`

Action serveur `'use server'` qui convertit un candidat en pièce.

Signature :
```ts
export async function convertCandidateToPart(
  candidate: SearchCandidate,
): Promise<{ success: true; partId: string } | { success: false; error: string }>
```

Comportement :
1. Vérifie le rôle ADMIN via `requireAdmin()` (`src/lib/auth-admin.ts`).
2. Génère un `partNumber` unique : `CAND-${Date.now()}`.
3. Crée une `Part` via Prisma :
   - `partNumber` (généré)
   - `name` : `candidate.name`
   - `description` : `'Converti depuis le workspace'`
   - `printableModelUrl` : `candidate.fileUrl`
   - `status` : `'DRAFT'`
4. Si `candidate.fileUrl` présente une extension CAO (`.stl`, `.step`/`.stp`, `.obj`), crée une `Attachment` avec le `fileType` correspondant (`CAD_STL`, `CAD_STEP`, `CAD_OBJ`) et `kind: 'CAD'`.
5. Retourne `{ success: true, partId }` ou `{ success: false, error }`.

Extrait :
```ts
'use server';

import { prisma } from '@/lib/prisma';
import { requireAdmin } from '@/lib/auth-admin';
import type { SearchCandidate } from '@/core/ai-engine/skills/search/types';

export async function convertCandidateToPart(
  candidate: SearchCandidate,
): Promise<{ success: true; partId: string } | { success: false; error: string }> {
  try {
    await requireAdmin();

    const partNumber = `CAND-${Date.now()}`;
    const fileUrl = candidate.fileUrl ?? null;

    let fileType: 'CAD_STL' | 'CAD_STEP' | 'CAD_OBJ' | undefined;
    if (fileUrl) {
      const ext = fileUrl.slice(fileUrl.lastIndexOf('.')).toLowerCase();
      if (ext === '.stl') fileType = 'CAD_STL';
      else if (ext === '.step' || ext === '.stp') fileType = 'CAD_STEP';
      else if (ext === '.obj') fileType = 'CAD_OBJ';
    }

    const part = await prisma.part.create({
      data: {
        partNumber,
        name: candidate.name,
        description: 'Converti depuis le workspace',
        printableModelUrl: fileUrl,
        status: 'DRAFT',
      },
    });

    if (fileUrl && fileType) {
      await prisma.attachment.create({
        data: {
          partId: part.id,
          name: candidate.name,
          url: fileUrl,
          fileType,
          mimeType: 'application/octet-stream',
          kind: 'CAD',
        },
      });
    }

    return { success: true, partId: part.id };
  } catch (error) {
    if (error instanceof Error) {
      return { success: false, error: error.message };
    }
    return { success: false, error: 'Erreur inconnue lors de la conversion' };
  }
}
```

## §4 — Risques

- **Aucun impact sur les flux stables** : `createPart` inchangé, `CandidateCard`/`AssistantZone`/`WorkspaceClient` conservent leur contrat existant. La prop `isAdmin` est optionnelle (défaut `false`), donc tout appelant existant sans la prop voit le bouton masqué (comportement identique à avant).
- **Sécurité** : le rôle ADMIN est vérifié côté serveur dans l'action (`requireAdmin`), le flag `isAdmin` côté client ne sert qu'à masquer/afficher le bouton (défense en profondeur, pas de contournement possible).
- **Données** : `partNumber` généré automatiquement (`CAND-{timestamp}`), pas de conflit d'unicité attendu à moins de deux conversions dans la même milliseconde (résiduel, acceptable pour un draft).
