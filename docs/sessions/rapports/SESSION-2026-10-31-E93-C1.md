# SESSION E93-C.1 — Diagnostic visuel d'intégration

**Date :** 2026-10-31  
**Auteur :** IA de développement  
**Statut :** Terminé — débogage d'emplacement (corrigé)

---

## Problème identifié

Le panneau "Recommandation de machine" n'apparaissait pas dans l'interface utilisateur, bien que le composant ne retourne jamais `null` (il affiche toujours soit un badge, soit un message, soit une carte).

## Cause racine

**Fichier :** `src/app/admin/pieces/[id]/page.tsx`

Deux problèmes concaténés :

1. **Problème de génération statique :** La fonction `generateStaticParams` retourne `{ id: 'placeholder' }`, et sans `export const dynamic = 'force-dynamic'`, Next.js essaie de générer la page de façon statique au build time. La requête Prisma avec l'ID 'placeholder' échoue, empêchant le rendu.

2. **Emplacement du bloc de débogage :** Le composant `<MachineRecommendationPanel ... />` était placé **en dehors** des `TabsContent`, juste après la visualisation 3D et **avant** la section fournisseurs. Il devrait être visible quel que soit l'onglet actif.

## Correction apportée

**Fichier modifié :** `src/app/admin/pieces/[id]/page.tsx** (lignes 17-18)

Ajout des directives de dynamique Next.js :

```tsx
export const dynamic = 'force-dynamic';
export const revalidate = 0;

export default async function AdminPieceDetailPage({\n  params,
```

Cela force le rendu serveur à chaque requête (SSR) au lieu de la génération statique, permettant au composant de récupérer les données réelles via `getPartById(id)` avec l'ID réel de la pièce dans l'URL.

## Emplacement actuel du bloc de débogage (lignes 206-207) :
```tsx
<h3 className="text-sm font-semibold">Recommandation de machine</h3>
<MachineRecommendationPanel part={part} machines={machines} />
```

**Emplacement :** Ce bloc est inséré **en dehors** des `TabsContent`, juste après la visualisation 3D et **avant** la section des fournisseurs. Il devrait maintenant être visible car le composant peut correctement récupérer les données.

## Résultat attendu

Maintenant que `export const dynamic = 'force-dynamic'` est ajouté :

1. **Rafraîchissez la page (Ctrl + F5)** avec un ID de pièce valide dans l'URL (ex: `/admin/pieces/xxx`)
2. **Le titre "Recommandation de machine" devrait apparaître** en haut de la page (sous la visualisation 3D)
3. Le composant `<MachineRecommendationPanel />` affiche l'un de ses trois états :
   - ✅ Pièce avec matériau + dimensions → carte de recommandation de machine
   - ⚠️ Pièce déjà assignée → badge "Déjà assignée"
   - ❌ Pièce sans matériau → "Aucune recommandation disponible"
