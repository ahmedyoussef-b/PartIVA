# Session E64-A - Rapport d'implantation torus et cone

**Produite le 2026-10-27**

## §1 — Contexte

Dans le cadre de l'audit E64 du module `reconstruct`, il a été décidé d'ajouter deux nouvelles primitives CAO à faible risque et haute valeur :
- **`torus`** (anneau/tore) — utilisant nativement `THREE.TorusGeometry`
- **`cone`** (cone) — utilisant nativement `THREE.ConeGeometry`

Ces formes ont été prioritaires par rapport au prisme et aux opérations booléennes car elles sont directement supportées par la bibliothèque `three` sans dépendances externes.

**Objectif E64-A :** Ajouter `torus` et `cone` au module `reconstruct` sans toucher aux flux stables.

```typescript
export type CadPartType = 'cylinder' | 'plate' | 'disc' | 'block' | 'sphere' | 'torus' | 'cone';
// generate-cad.ts
case 'torus': {
  const radius = toMm(params.radius ?? 20);
  const tubeRadius = toMm(params.tubeRadius ?? radius / 4);
  return new THREE.TorusGeometry(radius, tubeRadius, 16, 32);
}
case 'cone': {
  const radius = toMm(params.radius ?? DEFAULT_DIAMETER);
  const height = toMm(params.height ?? DEFAULT_HEIGHT);
  return new THREE.ConeGeometry(radius, height, 32);
}
```
