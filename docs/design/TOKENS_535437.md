## 3. Typographie (Font Stack & Échelles)

### 3.1. Polices Google Fonts à Importer

1.  **Police des Titres (Headings) :**
    *   **Famille :** `Poppins` (Google Fonts)
    *   **Graisses requises :** 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
    *   *(Note : le template propose également `Space Grotesk` en alternative pour les bannières modernes)*
2.  **Police de Corps (Body / UI) :**
    *   **Famille :** `Inter` (Google Fonts)
    *   **Graisses requises :** 300 (Light), 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
3.  **Police Code / Données Monospaces :**
    *   **Famille :** `Fira Code` (Google Fonts)

## 5. Synthèse de Configuration Tailwind 4 (Prête pour l'Étape 2)

Ces tokens s'injecteront directement dans `@theme` (spécification Tailwind v4) :

```css
@theme {
  /* Couleurs Fondamentales */
  --color-tech-navy: #072066;
  --color-tech-dark: #000000;
  --color-tech-primary: #1e88e5;
  --color-tech-primary-light: #64b5f6;
  --color-tech-accent: #2196f3;
  --color-tech-gradient-end: #0d47a1;
  --color-tech-surface: #ffffff;
  --color-tech-surface-subtle: #f8f9fa;
  --color-tech-border: #e0e0e0;
  --color-tech-border-dark: #30363d;

  /* Typographie */
  --font-heading: 'Poppins', sans-serif;
  --font-sans: 'Inter', sans-serif;
  --font-mono: 'Fira Code', monospace;

  /* Rayons */
  --radius-btn: 0.5rem;
  --radius-card: 1rem;
  --radius-pill: 50px;

  /* Ombres */
  --shadow-tech: 0 0 20px rgba(116, 116, 116, 0.1);
  --shadow-tech-hover: 0 20px 40px rgba(0, 0, 0, 0.15);
  --shadow-tech-glow: 0 0 20px rgba(30, 136, 229, 0.25);
}
```
