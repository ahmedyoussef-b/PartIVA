# AGENTS — PartIVA

**Type :** Instructions pour les agents de développement
**Version :** 1.0
**Statut :** À valider par le coordinateur

## 1. Objet

Ce document fournit les instructions générales pour les agents de développement compatibles (Kilo Code, etc.) travaillant sur le projet PartIVA.

## 2. Renvoi vers les procédures officielles

**Ce document ne remplace pas les procédures officielles.** Il les référence.

Les procédures officielles sont :

- `docs/gouvernance/CHARTE.md` — principes généraux.
- `docs/gouvernance/PROCEDURE_COORDINATEUR.md` — rôle du coordinateur.
- `docs/gouvernance/PROCEDURE_IA_INTERNE.md` — rôle de l'IA interne.
- `docs/gouvernance/PROCEDURE_IA_EXTERNE.md` — rôle de l'IA externe.

## 3. Règles générales

- Respecter les autorisations accordées par le coordinateur.
- Ne pas élargir le périmètre d'une tâche sans autorisation.
- Documenter les écarts et les blocages.
- Vérifier les résultats avant de déclarer une réussite.
- Mettre à jour `docs/etat/ETAT_COURANT.md` après chaque changement significatif.

## 4. Structure documentaire

| Fichier | Rôle |
|---|---|
| `docs/etat/ETAT_COURANT.md` | État actuel du projet |
| `docs/etat/DETTES.md` | Dettes actives |
| `docs/etat/DECISIONS.md` | Décisions validées |
| `docs/sessions/INDEX.md` | Index des sessions |
| `docs/gouvernance/CHARTE.md` | Principes de gouvernance |

## 5. Notes

- Les procédures existantes restent prioritaires.
- En cas de doute, demander un arbitrage au coordinateur.
